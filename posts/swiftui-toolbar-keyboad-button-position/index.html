【swiftUI】toolbar の.keyboardの完了ボタンが真ん中に来てしまう件

okapping 2026/11/15 23:50

ios26への対応をずいぶんと怠っていました。

重い腰が上がり見直してみると、修正すべき点がたくさんありました。

その中で自分がつまづいていたところの共有です。（大体全部つまづいています。）

目的

これを

こうしたい

どうすれば良いか。

元のソースはこうなっていました。

ToolbarItem(placement: .keyboard){
    HStack{
        Spacer()
        Button{
            focus = false
        }label: {
            Text("完了")
        }
    }
}

ToolbarItemの中にHStackを入れていた部分をToolbarItemGroupにして、HStackを無くして直接Spacer()とButton()を入れれば良いだけです。

ToolbarItemGroup(placement: .keyboard){
    Spacer()
    Button{
        focus = false
    }label: {
        Text("完了")
    }
}

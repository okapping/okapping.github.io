【Publii】ブログのフッターにブログ村のリンクを載せたい

okapping 2026/11/17 23:54

したいこと

↓これです。ブログ村にせっかく登録してみたので、フッター部分のメニューの中にブログ村のバーナーの載せたいと思いました。

ただ、Publiiでは直接フッター部分をエディターで弄ることができないので、少し遠回りが必要です。

手順

まずは、フッター部分のメニューにブログ村を追加します。

登録内容はこんな感じです。

ラベルは「ブログ村」。ここは見えなくするのでなんでも可

種類は「外部リンク」。

外部URLにはブログ村プロフィールページのプロフィールページURLを貼り付け。

↓これ

SCCクラスには「blogmura」と打って保存。

 

そして最後にもう一つ、カスタムCSSを記入します。

サイドバーの「ツール・プラグイン」から「カスタムCSS」を選択

以下を入力してください。

/*
 * フッターのブログ村用
 */

li.blogmura a {
  display: inline-block;
  color: transparent; /* 文字を透明に */
   user-select: none; /* 選択不可設定 */
  -webkit-user-select: none; /* 選択不可設定 Safari向け */
  width: 88px; /* 画像の幅 */
  height: 31px; /* 画像の高さ */
  background: url("https://b.blogmura.com/88_31.gif") center / contain no-repeat; /* 画像配置 */
}

これで狙い通りに表示されるようになっているはずです。

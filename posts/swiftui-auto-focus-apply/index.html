【swiftUI】sheetを開いた直後のfocus時に、toolbarの.keyboadが表示されない

okapping 2026/11/16 00:36

sheetを開いた直後に、フィールドにフォーカスして、ユーザーの入力動線をわかりやすくスムーズにすることはよくあると思います。

ただ、ios26での挙動をみると従来通りではいかなくなっていたのですが、

通常onAppearでfocusを当てるところを、遅延してfocusしてあげることで改善しました。

// OLD
.onAppear{
    self.focus = true
}
// NEW
.onAppear{
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.1) {
        self.focus = true
    }
}

非同期にすることで改善。これはあるあるですね。

self.focusにしないといけない点。注意です。

 

ではでは。
